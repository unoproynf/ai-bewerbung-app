# AI Bewerbung App

Simple web application built with Next.js for generating job application letters in German and English.

---

# Features

- Generate simple application letters
- German and English language support
- Clean and minimal interface
- Built with React and Next.js

---

# Technologien

- Next.js
- React
- TypeScript
- Tailwind CSS

---

# Projektbeschreibung (Deutsch)

Diese Webanwendung wurde mit Next.js entwickelt und dient zur Erstellung einfacher Bewerbungsanschreiben auf Deutsch und Englisch.

Der Fokus lag auf:
- Formularverarbeitung
- Benutzeroberfläche
- Grundlagen moderner Webentwicklung
